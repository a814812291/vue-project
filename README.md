# 涨停雷达面板

一个用于快速浏览当日 A 股涨停股的可视化面板（示例数据）。包含筛选、连板/游资统计、个股详情与近十日 K 线。

## 环境要求
- Node.js 14+
- npm 或 yarn

## 本地启动
```bash
# 安装依赖
npm install

# 启动开发服务（默认 http://localhost:8080）
npm run serve
```

## 使用方式
1. **顶部筛选**：输入股票名/代码/题材关键字，或选择行业并勾选“只看游资席位”以过滤列表。
2. **查看详情**：点击列表中的任意股票行，右侧会显示涨停原因、龙虎榜席位、核心指标以及近十日 K 线。
3. **观察情绪**：页面顶部的统计卡片实时显示今日涨停数量、最高连板高度、游资席位数量和今年以来平均涨幅。

> 当前数据为内置示例，接入实盘接口后即可每日打开即用。
